# Took

**입력 전용 웹 앱(PWA).** 글 상자 하나에 적고 저장하면, 로그인한 사람 자신의 Google Drive 안 앱 전용 폴더(`Took`)에 마크다운 파일로 저장된다.

- 오프라인에서 적은 것은 기기에 대기했다가 연결되면 보낸다
- 저장 후 5분 안에는 수정·취소(지우지 않고 "취소됨" 표시)
- 다른 앱에서 **공유 → Took**로 링크 저장("왜 저장하나" 한 줄 필수)
- "민감" 체크 시 파일 이름에 내용을 넣지 않는다
- Drive 권한은 `drive.file`(이 앱이 만든 파일만 접근)

## 개인정보
- 이 저장소에는 키·비밀값·개인 데이터가 없다. 서버도 없다(정적 파일만).
- 입력은 접속한 사람의 브라우저와 그 사람의 Drive에만 저장된다. 다른 곳으로 보내지 않는다. 분석·추적 스크립트도 없다.
- `config.js`의 `clientId`가 비어 있으면 **모의 모드**다. 입력은 그 브라우저 안에만 남는다.
